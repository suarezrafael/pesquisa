# app

Este é o jogo (React + TypeScript + Vite + Babylon.js). Veja o [README na raiz do
repositório](../README.md) pra visão geral do projeto, arquitetura e stack completa.

```bash
npm install
npm run dev       # servidor de desenvolvimento
npm run build      # typecheck + build de produção
npm run preview     # serve o build de produção localmente
```
